# Demo script: Harvest AI project setup (Concept B)

Sketch: concepts/b-inline/admin.html at 1440x900. Open it with `?demo` at the end of the address to hide the sketch strip, and reload before recording (it starts in Strong).

Keys, not shown on screen: Ctrl+1 Strong, Ctrl+2 Conflicting, Ctrl+3 Thin, Ctrl+4 None (each switches and runs the estimate). Ctrl+0 shows or hides the sketch strip.

| #   | Action                                                                    | Caption                                                     |
| --- | ------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 1   | Type "New website for Fernwood", click Estimate                           | -                                                           |
| 2   | Client and Project name fill in. Click "Estimating 358 h from 5 projects" | The AI finds similar past projects and creates an estimate. |
| 3   | Page moves to Tasks and hours. Pause on the banner and table              | Every number comes from tracked time.                       |
| 4   | Click "View references"                                                   |                                                             |
| 5   | Untick "Tallgrass Co: Brand website" (note: Time tracked late)            | Leave out a project that doesn't fit.                       |
| 6   | Close the panel.                                                          |                                                             |
| 7   | On Development, point at "Over by 8-30 h in 2 of 4", click "4 references" |                                                             |
| 8   | Drawer shows the 4 projects. Change Development budget to 150             |                                                             |
| 9   | Line reads "Estimating 383 h from 4 projects". Click "Hide references"    |                                                             |


Numbers checked in the sketch on 2026-11-23.
