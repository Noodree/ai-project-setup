# AI project setup from past projects

A design exploration and portfolio case study: when a lead creates a new project in a time-tracking and invoicing tool, AI finds similar past projects and fills the tasks and budget from their tracked time. Every number shows which past projects it came from, and the lead can leave any of them out.

All clients, people, projects and numbers are invented.

## Open the sketch
Open `concepts/b-inline/admin.html` in a browser (one file, no build step). Type a project description and click Estimate.

- Add `?demo` to the address to hide the sketch controls.
- Ctrl+1 to 4 switch between the evidence states (Strong, Conflicting, Thin, None). Ctrl+0 shows or hides the controls.
